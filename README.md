# Backend agent pack
Copy `CLAUDE.md` and `docs/` into the root of the backend repo, open it in VS Code, and paste the prompts from `docs/prompts/CLAUDE_Prompts_Backend.md` one at a time, in order. `docs/TASKS.md` is the progress tracker the agent reads and updates.
Nothing outside these files is needed. Do not commit until you have reviewed each slice.
